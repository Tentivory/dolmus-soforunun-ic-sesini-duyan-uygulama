# Dolmuş Şoförünün İç Sesini Duyan Uygulama

## Bu Nedir?

Bu proje, insanlığın en büyük gizemlerinden birini çözmek için tasarlanmıştır: **Dolmuş şoförü ne düşünüyor?**

Yolcular "durak mı?", "inecek var!" diye bağırırken, şoförün içinden geçen o derin, felsefi, öfkelı veya tamamen saçma cümleleri artık duyabilirsiniz.

**DİKKAT:** Bu uygulama bilimsel olarak kanıtlanmıştır. Laboratuvar testlerinde 3 dolmuş şoförü ağladı, 1'i "beni anladınız" dedi.

## Nasıl Çalışır?

1. `python dolmus_sesi.py` çalıştırın.
2. Yolcu sayısını girin (veya girme, o da olur).
3. Şoförün iç sesini dinleyin.
4. Şoka girin.
5. Tekrar çalıştırın.

## Özellikler

- Gerçek zamanlı iç ses analizi (rastgele)
- Yolcu sayısına göre öfke seviyesi artışı
- Felsefi derinlik (yok)
- Trafik sıkışıklığında ekstra küfür potansiyeli
